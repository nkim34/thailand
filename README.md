# Amazing Thailand — Summer Vacation Website

## Setup Instructions

1. **Add your video**: Rename your AI-generated video to `video.mp4` and place it in this folder.
2. **Add your image** (optional): Save your AI-generated image as `thailand_ai.jpg` and update the `src` in `content.html`.
3. **Upload everything** to your GitHub repository root.

## Files
- `index.html` — Landing page with video background + CTA button
- `content.html` — Gallery page with destinations, experiences, AI image
- `video.mp4` — (you add this) AI-generated video
